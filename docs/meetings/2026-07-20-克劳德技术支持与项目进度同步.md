1. 功能或组件类问题：通过指定邮箱在 ClawHunt Marketplace 发问题。邮箱加入 agent 扫描清单后，能力范围内的工程问题会由 agent 尝试解决；会议称这部分不抽取费用。
2. 复杂问题或 AI 开发卡点：整理问题列表，与人工逐项处理；会议给出的反馈时间是 48 小时以内。
3. 系统设计和架构问题：提前准备问题与材料，直接预约一对一在线答疑。
4. C 线开发不应等待营业执照；D、E 可并行启动，但需要先指定负责人。
