# 定价研究：国内 3D 打印代打行情 + 嘉立创三维猴一手价目（2026-07-19）

用途：为 C 线 §二「价格真值」拍板提供事实基础（WP-B7-1 Material/PricingRule seed 的证据来源）。两条研究线：市场面（淘宝 + 服务商公开页，opencli 只读）与嘉立创专项（agent-browser 实浏 + 站内公开 API）。**本文件只记事实与置信度，定价决策另由用户拍板后写入 C 线执行文档。**

## 一手数据（高置信）

### 嘉立创三维猴实时价目（2026-07-19 抓取）

报价页公开 API `POST jlc-3dp.cn/3dp/material/getAllEnableMaterialInfo`（未登录可访问）返回全部 40 种材料实时价目。**全量原始数据：`assets/pricing-research/jlc-materials-raw-2026-07-19.json`**。要点：

- 计价一律「元/克」，重量 = 体积 × 材料密度（API 带 `materialDensity`，树脂统一 1.3 g/cm³）；同一材料按交期分档（越快越贵）；每种材料固定一色，换色靠喷漆。
- 代表档位（默认交期，元/g｜起步价）：树脂 9600 哑光白 0.38｜1.77（批量最低 0.32，加急 12h 档 0.57｜30）；X 树脂随机色 0.23；CBY 淡黄 0.60；类 PLA：PLA-C 糖果混色 0.20｜4.43、PLA-P 黑 0.50｜4.87；尼龙 1.00～1.70；TPU 0.61；ABS 1.20；金属 1.00～2.55。
- 起步价按「材料×交期档」独立设定（普通树脂 1.77 起，工程塑料 ~20，金属 ~48.68，全彩 26.55~30）；官方口径「单个成品低至 2 元」。
- 后处理：去支撑/清洗/固化/打磨喷砂免费含在打印价内；**喷漆**仅白树脂 9600/LEDO 6060 单色 + 8001 全透喷油，「10 元起、费用主要与表面积有关」（2023-05 文章更新至 2025-05，费率现时性低置信），Pantone C/U 色卡选色、推荐 10 色内、人工喷涂非工业级、交期 +~2 天。
- 展示口径：人民币、**报价页明示「总计(不含税)」**、金额保留两位小数（精确到分，无取整习惯）、可开发票；运费按重量 + 大体积附加，付款时实时核算，新客券免邮覆盖率官方称 ~70%。
- 流程：上传（stl/stp/step/obj/3mf，<100M）→ 选材料/数量/交期/表面处理 → 人工审核 10-60 分钟 → 付款；异形件/大量支撑/小件备份视情况加收并加 1-2 天交期。

### 淘宝实测（opencli 只读，详情页原文）

- 代打服务标准形态 = 「¥N 起」引流价（¥1~¥10），实际按上传文件核价；列表价 ≠ 成交价。
- **同类成品零售锚点**：3D 打印仓鼠/花枝鼠躲避屋成品 ¥16.7 / ¥56.43 / ¥73.72（详情页确认）；定制人偶摆件（照片建模）¥184~240；混合材质大件（亚克力笼+打印配件）¥129。
- 运费主流「包邮」内含；币种全部 CNY，无含税/不含税标注；小数位无统一惯例。

## 与本项目的直接关联（事实，非决策）

- 首发单品奶酪软垫小床 landing 演示数据 180g/PETG/¥89：按嘉立创 9600 树脂 0.38 元/g 折算材料成本 ≈ ¥68（+喷漆 10 起）；按批量档 0.32 ≈ ¥58。
- 竞品成品零售区间（¥16.7~73.72）低于 landing 演示价 ¥89；定制类锚点（¥184~240）高于它。
- 材料安全张力：landing 对花枝鼠承诺「PETG / 圆角安全处理」，而一手价目最扎实的是 SLA 光敏树脂——啃咬类宠物的材料/涂层安全性需在材料拍板与 B6 检查口径中显式处理。
