# 竞品参考:嘉立创 3D 打印下单流程与 3D Viewer(2026-07-19)

- 来源:用户 2026-07-17 录屏《3D置景 3D编辑器预览需求以及电商模块参考.mp4》(5'38",含旁白),2026-07-19 结构化分析并经用户逐项确认。
- 竞品身份:**嘉立创(JLC)**——团队 leader Max 指认的**制造供应商**,其官网被明确要求"借鉴逻辑与下单流程"。涉及三个站点:
  - `jlcfa.com`(嘉立创FA·整机智造:上传→解析→参数表格→自动报价→一键提交)
  - `jlc-3dp.cn` / `model.jlc-3dp.cn`(嘉立创3D打印:散件下单 + 「好物集市」预设商品商城)
  - `3d-viewer.jlc.com`(独立 3D 模型查看器,免费,"Powered By JLC 3D Model Viewer",附格式转换)
- 定位提醒:嘉立创面向**工程师**,PetScape 面向**宠物主**。本文档参考的是**能力与流程逻辑**,不是工具箱式 UI 本身;高价值能力应融入任务流步骤自动呈现,而非平铺工具栏(用户确认的总原则)。

## 一、端到端电商流程拆解(嘉立创 FA 整机智造)

| # | 步骤 | 页面事实(视频可见) | 对 PetScape 的作用/衔接 |
|---|---|---|---|
| 1 | 登录 | 首页弹窗:扫码 / 账号 / 手机号三 Tab,"下次自动登录" | 对应 A3(已有 Better Auth 双凭证) |
| 2 | 上传 | 拖拽上传整机/装配体/压缩包;支持 3D(step/stp/stl/3mf/obj)、2D(dwg/dxf/pdf)、Excel BOM(上传后自动检测弹窗引导);≤100M;显著的保密/知识产权承诺文案 | PetScape 用户不上传模型(由 B4 生成),但"保密承诺"文案的信任感设计可借鉴 |

| 6 | 提交 | 「一键提交全部(N)」单按钮收口 | 对应 C1/C2→C3 的转化收口:一个主按钮,不给用户分叉 |

**散件下单页**(`jlc-3dp.cn/placeOrder`)与整机智造同构:选择工艺(多零件/3D打印/CNC/钣金/手板复模)→ 上传 → 历史上传记录。

**「好物集市」商城**(`model.jlc-3dp.cn`):预设商品卡片流——实拍图(非渲染图)、名称、标签(玩具/解压/手办)、"¥7.78 起"、立即购买;顶部搜索+分类。用户旁白:"他们也有可选的商城预设模板,支付功能就在这里。"

### 流程要点总结(转化设计)

1. **报价零等待、零沟通**:从上传到含税价全自动,"价格有吸引力,不惧比价"的透明定价是嘉立创的核心卖点(页脚:品质好/阳光透明/交期快/价格优)。
2. **状态可量化**:解析进度、工艺编辑完成度(0%→100%)、待完善数,每一步都告诉用户"离下单还差什么"。
3. **单按钮收口**:全流程终点收敛到「一键提交全部」。
4. **信任装置**:自动保存、保密承诺、明码实价、专属客服。

## 二、3D Viewer 交互与视觉清单

载体两处:①整机智造表格行内"预览"→ 右侧抽屉式侧栏;②独立站 `3d-viewer.jlc.com`(全屏,功能全集,另有格式转换/上传预览/小程序入口)。

### 工具全集(视频可见)

回到原点 / Rotation / Pan / Measurement(M) / Model properties / Sectioning / Tree Structure / Explode / Bounding Box / Drag / Box Zoom / Auto color Assignment / Real time location / Axis / Basic information / Model Effects / Show/Hide / Screenshot / Full Screen / Settings / Share / 视角立方体(FRONT/RIGHT/BOTTOM,右上角)

### 关键工具行为细节

- **Measurement**:逐轴尺寸标注气泡(实测模型:x:8.70mm / y:10.45mm / z:52.16mm / ~27.20mm),直接贴在模型上。
- **Model properties**:Basic properties(Volume 92263.65mm³ / Surface Area 26238.41mm² / Bounding Box 59.29×61.43×120.95mm / Bounding Box Volume / **Preset Material 下拉(铝合金 2.7g/cm³)→ Weight 249.11g 自动算**,各数值带一键复制)+ Scene properties(点数 290 万 / 三角面 96.8 万)。
- **Drag**:进入即全屏提示"Press Esc to exit"+"Hold and drag to move model"游标提示;子工具 Single drag / Single reset / Reset all。
- **Auto color Assignment**:一键给灰模上色(演示中变金色)。
- **Sectioning**:剖切查看内部。
- 独立站额外:Screenshot、Share、格式转换(STP/X_T/IGS/SAT/WRL/STL/IFC,≤100M,"不发布不分享、定期删除"承诺)。

### 视觉要点

- 米白/暖白纯色背景,浅灰哑光材质渲染,地面软阴影(方向光,影子拉长有戏剧感)。
- 工具栏 = 白色圆角胶囊浮层,图标+小字标签,底部居中,可折叠(Collapse);侧栏模式精简为 4 项(回到原点/Explode/Transparent/More»)。
- 与 PetScape 视觉基准(白底纯黑、胶囊、玻璃拟物)**天然相容**:胶囊工具栏、暖白场景底、软阴影都可直接融入;冲突点仅在嘉立创的工程蓝主色与图标密度——我们应更少的工具、更大的留白。

### 用户旁白定调(逐项确认记录,2026-07-19)

| 元素 | 用户表态 | 处置 |
|---|---|---|
| 3D 预览整体 | "我很想要的功能,黑客松项目里就是想做这个效果;**但他只有单品预览,我要的是用户场景 1:1 复刻,用户可在里面布置、自由拖动**" | 核心方向,落 B5 |
| 旋转 / 测量 / 重量属性 / Drag 拖放 / 单独重置 / 阴影 | 旁白点名有用("测量很有用,能看整体高度";"Drag 非常有用") | 纳入参考清单 |
| 视角立方体 + 回到原点 | 分析建议纳入(3D 新手"转丢找不回"的安全网,现成 gizmo 低成本) | ✅ 用户确认纳入 |
| Bounding Box 尺寸常显 | 分析建议纳入(B5 尺寸确认场景比测量工具更直接:长宽高常显,测量作进阶) | ✅ 用户确认纳入 |
| 重量→报价透明推导 | 分析建议纳入(体积×密度=重量=报价输入,做成用户可见的信任感设计) | ✅ 用户确认纳入 |
| Sectioning 剖切 | 用户旁白"不确定";分析:宠物主不需要,但 B6 审核人员查壁厚/内腔有用 | ✅ 确认转 B6/D1 内部工具灵感,不进 C 端 |
| Tree Structure | 装配体部件树,单物品 MVP 无用;B5 场景对象列表是另一件事,按场景设计 | ✅ 确认不参考 |
| Explode / Box Zoom | 工程场景专属 | ✅ 确认不参考 |
| Auto color Assignment | 用户:"希望可以**自己上色,类似贴图**"(自动配色不是诉求) | ✅ 确认记入 B10 启发点 |
| 格式转换 | 用户:"对我们可能没用" | ✅ 确认不参考 |
| 「好物集市」预设商城 | — | ✅ 确认记为 P2 新灵感(预设精选商品/模板库,关联 E8 复购与 B2 方案选择),不进模块表 |
| Viewer 功能总量 | "我肯定要这个,但具体功能不需要这么多,配多少是可讨论的点" | 总原则:参考能力,融入任务流,不抄工具箱 |

## 三、与 PRODUCT-MODULES 的映射表
