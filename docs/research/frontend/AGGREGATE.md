## 1. 执行摘要

- **这是什么**：一个宠物（异宠为主）3D 打印定制电商的**前端原型 SPA**。产品叙事：用户从熟悉物种入口进入 → 创建宠物档案 → 上传照片生成"游戏角色式"3D 形象 → 添加付费装扮 → 浏览白底标准化打印模块 → 加入 3D 环境预览 → 看报价 → 走订单闭环。站内 `<title>` 是 "TinyHabitat AI"，而 logo 文件名 / CSS class 前缀是 "PetScape"，属**命名漂移**而非两个项目（`_map.md:9,127`）。
- **技术形态**：React 18 + Vite + `motion`（Framer Motion 继任）+ `lucide-react`。**纯前端 SPA，无路由库，单页长滚动**。全部代码集中在两个文件：`src/main.jsx`（266 行，20 个组件全内联，无 `components/` 目录）+ `src/styles.css`（2471 行）。`tools/process_pet_assets.py` 是**构建时素材加工脚本**（把设计师原图裁成 1400×980 白底圆角图），非运行时逻辑（`_map.md:7-11`）。
- **有状态还是纯静态**：**混合，但以静态展示为主**。顶层 `App` 持有 8 个 state + 1 个 ref（`drawerOpen / selectedSpeciesId / selectedIds / petName / petSize / petImageUrl / avatarGenerated / avatarRotation / selectedWearables`，`main.jsx:245-263`），串起 5 个"真交互"区块（物种轮播、宠物创建器、装扮商店、模块社区、环境预览）；其余区块（内容营销、报价、礼物、订单流程条）是纯静态写死数组渲染。**全项目无一处网络请求 / 异步 / 持久化**——刷新即丢全部状态。
- **src / dist 以哪边为准**：**以 `src` 为准**。`src/main.jsx`（mtime 2026-07-04 17:41:14）比构建产物 `dist/assets/index-*.js`（17:15:02）新。逐条比对 dist 提取的 344 条中文串，仅 2 处差异且均已被 src 覆盖为更新态：① "查看更多"展开态文案 dist="爱宠社区已展开" → src="收起"；② GiftSection 素材 dist=占位卡 → src=真图 `gift-keychains.jpg`。其余全一致，dist 无独有隐藏组件/功能（`_map.md:54-66`）。

**状态词表**（下文"当前状态"列统一用词）：
- **真交互**：有 onClick/onChange + 真实 state 回调，视觉/数据真实响应（但状态不持久化）。
- **真上传/真计算**：浏览器端真实生效（文件选择+本地预览 / useMemo 求和），无服务端。
- **写死展示**：纯静态，数据来自硬编码数组/字符串，无交互。
- **有壳无芯**：结构完整、视觉像可点，但**无 onClick**，点击无反应。
- **完全缺失**：PRD 要求但前端连 state/props/JSX/CSS 痕迹都没有。
