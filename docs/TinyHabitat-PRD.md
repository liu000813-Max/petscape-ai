# TinyHabitat AI 产品需求文档 PRD

> 文档状态：2026-07-10 完成黑客松后产品方向校准。本文件是产品定位、用户承诺与范围边界的单一真相源；当前代码已经做到哪里，以 `integration-mapping.md` 和实际代码为准。

## 1. 产品概述

TinyHabitat AI 是一个面向爬宠与小宠用户的 AI 灵感与单件制造平台。用户创建宠物档案、上传当前饲养环境照片，并用自然语言描述想要的 vibe。平台先生成有吸引力的整体改造效果图，帮助用户看见自己想要的宠物空间；用户再从效果图中选择感兴趣的物品，将这份物品意图转化为可以预览、确认、报价和打印的单个模块。

产品核心是把“我想要一个更好看的宠物空间”转化为“我看中了其中这个物品，并且它可以被真实制作出来”的消费链路。整张效果图负责激发想象，3D 场景负责近似预览，经过确认的可打印单件负责制造和交付。三者表达同一份需求的不同阶段，不承诺彼此 1:1 等同。

## 2. 产品定位

### 2.1 一句话定位

帮助爬宠与小宠用户从 AI 宠物空间灵感图中发现想要的物品，再把它转化为可确认、可打印、可交付的单件模块。

### 2.2 目标用户

- 养花枝鼠、仓鼠、守宫、鬃狮蜥等宠物的新手与进阶玩家
- 喜欢布置宠物生活环境、愿意为审美和安全付费的用户
- 小红书、抖音、B 站等平台有分享欲的宠物内容用户
- 想购买标准化 3D 打印宠物配件的用户
- 有定制需求但缺少建模、打印和材料知识的用户

### 2.3 核心价值

- 对用户：先通过整体效果图完成想象，再选择真正想制作的物品，不要求用户先理解模块目录或建模规则。
- 对商家：用 AI 效果图激发需求，再通过现有商品匹配、模板化定制和人工辅助原创建模控制交付风险。
- 对内容传播：生成适合小红书传播的宠物环境分享图，帮助用户自传播。
- 对供应链：只对经过确认的可打印单件承诺材料、重量、打印周期和报价，不用整张效果图反推制造事实。

## 3. 用户痛点

### 3.1 当前问题

- 用户很难想象一个普通笼箱能被改造成什么样。
- 宠物配件大多以单品售卖，缺少整体环境方案。
- 小宠和爬宠对材料、安全、尺寸、习性要求不同，新手很难判断。
- 传统定制需要沟通、画图、建模、报价，流程重且不透明。
- 3D 打印产品缺少直观预览，用户不知道买回去是否适配自己的环境。

### 3.2 机会点

- 用 AI 效果图做“装修前后对比”，先刺激用户想象力。
- 让用户主动选择图中感兴趣的物品，把不确定的整图理解收敛为明确的单件需求。
- 优先通过现有商品匹配和模板化定制交付，无法可靠自动化的原创需求进入人工确认。
- 用宠物档案沉淀复购基础。
- 用白底标准商品模块承接低价引流与批量售卖。
- 用场景包承接高客单价整装方案。
- 用首单宠物小模型挂件提升仪式感和分享欲。

## 4. 产品目标

### 4.1 Web V1 目标

第一阶段验证用户是否愿意完成从灵感到单件定制申请的真实链路：

- 创建宠物档案
- 上传当前环境照片
- 输入想要的 vibe
- 浏览 AI 改造效果图
- 从效果图中选中一个感兴趣的物品
- 接受现有商品匹配或模板化定制结果
- 在 3D 场景中查看该物品的近似摆放效果
- 确认单件模型、材料、重量、周期和价格
- 提交定制申请，由人工完成复核、收款、打印和发货

### 4.2 商业目标

- 用免费 AI 效果图获取用户线索
- 用标准模块或模板化定制单件完成首单转化
- 用人工辅助的原创单件承接更高定制需求
- 用宠物档案和模块扩展完成复购

## 5. 核心用户流程

### 5.1 主流程

1. 用户进入首页，看到动态宠物环境 KV。
2. 用户选择宠物品种，例如花枝鼠、仓鼠、豹纹守宫、睫角守宫、鬃狮蜥。
3. 用户创建宠物档案：名字、品种、性格标签、体型、照片。
4. 系统展示该品种的习性、风险和材料建议。
5. 用户上传当前饲养环境照片。
6. 用户输入 vibe 描述，例如“森林奶酪屋、童话厨房、适合钻洞和觅食”。
7. 系统生成 AI 整体改造图。
8. 用户查看 Before / After / 小红书分享图。
9. 用户从效果图中选择一个感兴趣的物品，并说明希望保留的造型、用途或主题特征。
10. 系统判断该需求适合现有商品匹配、模板化定制，还是需要人工辅助原创建模。
11. 系统展示候选单件模型，并把它放入 3D 场景做近似摆放预览。
12. 用户调整摆放、确认尺寸和单件模型；3D 场景不承诺还原整张效果图。
13. 系统展示该单件的材料、重量、生产周期和报价。
14. 用户提交定制申请。
15. 商家人工复核、联系收款、打印、质检和发货。

### 5.2 标品社区流程

1. 用户进入白底标品社区。
2. 查看标准化 3D 打印模块。
3. 模块展示清晰白底图、名称、价格、材料、重量、适配物种。
4. 用户点击“加入 3D 场景”。
5. 模块进入当前宠物环境预览。
6. 用户查看模块报价并提交定制申请。

### 5.3 效果图选物后的交付路径

用户选中的物品进入以下三种路径之一：

1. **现有商品匹配**：商品库已有足够接近的可打印模块，用户直接查看真实模型、尺寸和报价。
2. **模板化定制**：基于已验证的结构模板修改主题、外观、比例或颜色，保留安装、安全和打印边界。
3. **人工辅助原创**：现有商品和模板均无法表达用户意图时，进入人工评估与建模；Web V1 不承诺自由图片转 3D 全自动完成。

系统需要明确告诉用户当前采用哪条路径，以及最终模型与灵感图之间可以承诺的相似程度。

## 6. MVP 功能范围

### 6.1 首页首屏

目标：快速建立产品质感和传播感。

功能要求：

- 全屏动态视频 KV
- 极简导航
- 中文品牌表达
- 主 CTA：开始定制
- 次 CTA：浏览标品
- 不使用大面积白色渐变遮挡视频
- 保证移动端能看到宠物主体

### 6.2 宠物品种选择

首批物种：

- 花枝鼠
- 仓鼠
- 豹纹守宫
- 睫角守宫
- 鬃狮蜥

功能要求：

- 每个物种有独立卡片
- 展示物种名称、英文名、习性标签、材料建议、适合环境
- 支持添加新物种入口
- 选择物种后，下方推荐对应标品模块

### 6.3 宠物档案

字段：

- 宠物名字
- 品种
- 照片
- 体型大小
- 性格标签
- 居住环境类型

功能要求：

- 支持上传宠物照片
- 支持生成宠物 3D 角色预览，作为首单礼物和传播支线
- 支持旋转查看
- 支持装扮商品添加

### 6.4 习性与材料建议

目标：让用户觉得平台懂宠物，而不是只做外观。

花枝鼠优先建议：

- 喜好：钻洞、攀爬、觅食、社交、多层空间
- 风险：尖角、小零件、卡尾巴缝隙、难清洗结构
- 推荐材料：PETG、圆角处理、可拆卸结构
- 不建议材料：易碎材料、强气味涂层、难清洁多孔结构

### 6.5 上传与 Vibe 描述

功能要求：

- 上传当前笼箱照片
- 上传宠物照片
- 输入自然语言 vibe
- 点击生成按钮
- 生成过程展示进度、失败原因和重试入口

示例 prompt：

> 森林奶酪屋，童话厨房氛围，适合花枝鼠钻洞、觅食和攀爬，保留原本笼箱结构，只添加可拆卸 3D 打印模块。

### 6.6 AI 效果图

展示位置：

- 改造前环境图，比例 4:3
- AI 改造后效果图，比例 16:9
- 小红书分享图，比例 3:4

功能要求：

- 让用户直观看到整体化装修效果
- 不只展示单品
- 可用于社媒传播
- 后续支持保存、分享、生成海报
- 明确标注效果图用于灵感表达，不代表最终可打印结构或 1:1 交付效果
- 支持用户从效果图中指出感兴趣的物品，并补充想保留的特征

### 6.7 效果图选物与需求确认

功能要求：

- 用户可以在效果图中选择一个感兴趣的物品
- 系统把选择结果表达为“物品意图”，包括物品类别、用途、主题和用户希望保留的视觉特征
- 系统展示现有商品匹配、模板化定制、人工辅助原创三种交付路径中的实际结果
- 用户在进入 3D 预览和报价前，能够看到当前路径及相似度边界
- 系统不把选中的二维区域直接视为已经可打印的三维模型

### 6.8 整装场景包

示例场景包：

- 森林奶酪屋
- 都市基地
- 雨林树屋

功能要求：

- 每个场景包展示整体效果图
- 标注适合物种
- 标注包含模块
- 标注起售价
- 允许用户从场景包选择其中一个模块或提交多模块定制申请

### 6.9 白底标品社区

目标：承接大批量售卖和低价转化。

功能要求：

- 商品图为干净白底
- 商品信息清晰：名称、价格、材料、重量、适配物种
- 支持“查看更多”进入完整标品社区
- 支持点击“加入 3D 场景”
- 支持记录已加入模块数量

首批标品：

- 奶酪洞穴窝
- 双通道连接管
- 圆角攀爬平台
- 食盆固定座
- 守宫湿躲屋
- 宠物姓名牌
- 晒背平台
- 荒漠岩石斜坡

### 6.10 3D 场景预览、单件模型与打印报价

功能要求：

- 3D 场景用于近似展示所选模块放入宠物环境后的空间感，不默认承担整张效果图的 1:1 重建
- 用户未提供真实环境尺寸时，页面明确标注为氛围预览；输入尺寸和安装约束后，才展示适配判断
- 最终制造确认聚焦单个可打印模块，并展示该模块的真实 3D 模型
- 展示材料选项
- 展示重量估算
- 展示生产周期
- 展示价格区间
- 报价绑定经过确认的单件模型版本，不从效果图或近似场景预览直接推算

报价逻辑示例：

- PETG：¥0.42 / g
- PLA+：¥0.28 / g
- 后处理：¥49 起
- 预计生产周期：2-4 天

### 6.11 首单礼物

功能要求：

- 首单赠送宠物专属小模型挂件
- 挂件绑定宠物档案
- 可作为用户分享点
- 后续可发展为付费周边

## 7. 订单闭环

### 7.1 当前 Demo 表达链路

免费生成图 → 选择宠物 → 创建形象 → 添加装扮 → 添加模块 → 确认模型 → 3D 打印 → 发货

该链路是黑客松演示状态，不代表 Web V1 已经具备真实订单、支付、生产和物流能力。

### 7.2 Web V1 真实交易链路

1. 用户免费生成 1-3 张效果图。
2. 用户从效果图中选择一个物品，或从商品库选择一个模块。
3. 系统给出现有商品匹配或模板化定制结果；无法可靠自动化的需求进入人工评估。
4. 用户查看单件模型及其在 3D 场景中的近似摆放效果。
5. 用户补充环境尺寸、安装位置和希望保留的特征。
6. 用户确认可打印单件版本，并查看材料、重量、生产周期和报价。
7. 用户提交定制申请和联系方式。
8. 商家人工复核、联系收款并确认生产版本。
9. 商家完成打印、后处理、质检和发货，并人工更新状态。

Web V1 不要求完整支付、自动排产、物流对接或社区系统。人工履约是已确认的产品边界，不影响前台验证从灵感到实物交付的完整故事。

## 10. AI 与外部服务依赖

### 10.1 生图模型

用途：

- 根据用户环境照片和 vibe 生成整体改造图
- 生成小红书分享图
- 生成商品视觉或场景概念图

输入：

- 当前环境照片
- 宠物照片
- 物种
- 用户 vibe
- 安全规则

输出：

- 改造效果图
- 分享图
- 场景包概念图

边界：

- 效果图表达主题、氛围和整体想象，不直接证明图中物品能够打印
- 效果图可以包含商品库之外的物品；用户选中后仍需经过交付路径判断
- 页面需要区分灵感图与最终单件模型，避免形成 1:1 交付预期

### 10.2 3D 模型生成

用途：

- 为用户选中的单件物品生成或匹配可预览模型
- 在真实尺寸、安装和安全约束下形成可打印单件
- 输出供报价、人工复核和生产确认的模型版本

交付路径：

- 现有商品匹配：直接使用已经验证的模块模型
- 模板化定制：在可制造结构模板上调整主题、外观和尺寸
- 人工辅助原创：自动结果只作为草稿，由人工补足隐藏面、结构、安装和安全信息

自由图片转 3D 可以作为辅助能力，但不是 Web V1 完成交易闭环的前置条件。

### 10.3 3D 打印服务

用途：

- 材料选择
- 重量计算
- 打印周期估算
- 订单排产
- 物流发货

关键字段：

- 材料
- 克重
- 打印时间
- 后处理
- 质检状态
- 发货状态

每个可打印单件需要分别通过模型可打印性、实物打印与装配、宠物接触安全三层确认。切片成功只证明模型能够进入切片流程，不代表实物已经适合宠物使用。

- 用户能理解从宠物档案、灵感图、选中物品到单件实物交付的链路
- 用户能理解 AI 效果图用于整体灵感，不是最终单件模型或 1:1 交付承诺
- 用户能从效果图中表达自己喜欢的物品及希望保留的特征
- 用户能看见当前需求采用现有商品匹配、模板化定制或人工辅助原创中的哪条路径

- 自动化结果不满足制造条件时进入人工复核，不直接承诺生产

## 13. 后续版本规划

### Web V1：灵感到单件申请

- 真实上传宠物与环境照片
- 生成 Before / After 灵感图
- 用户从效果图中选择一个物品并补充想保留的特征
- 优先完成现有商品匹配和模板化定制
- 展示近似 3D 场景与真实单件模型
- 展示单件材料、重量、周期和报价
- 提交定制申请，由人工复核、收款、生产和发货

### Web V1.x：人工辅助原创

- 为商品库和模板无法覆盖的需求提供人工评估
- 自动生成结果作为建模草稿，不直接进入生产
- 用户确认最终单件版本后再报价和生产

### V2：交易与复购系统

- 用户账号与宠物档案云端保存
- 支付、订单、生产状态和物流
- 已购模块与栖息地扩展记录
- 分享、晒单和复购权益

iOS App 和微信小程序复用同一套宠物、灵感、物品意图、可打印单件和订单数据；客户端形态不改变上述产品边界。

## 14. 关键风险

- AI 效果图与最终单件之间存在落差，用户可能把灵感图理解为 1:1 交付承诺
- 商品匹配如果只保留物品类别，没有保留用户喜欢的造型、主题或用途，用户会认为结果与图片无关
- 单张图片缺少隐藏面、内部结构、真实尺寸和安装方式，单件图片转 3D 仍然需要约束或人工补足
- 3D 场景在缺少真实环境尺寸时只能表达空间感，不能承诺适配
- 自由图片转 3D 的稳定性不足，不能成为 Web V1 完成首单的唯一通路
- 不同宠物对安全和材料要求不同，需要专业校验
- 能切片不等于能稳定打印、安装和供宠物安全使用
- 3D 打印成本、工期和质检会影响履约体验
- 用户可能喜欢效果图但不愿为整装方案付费
- 用户是否会持续购买模块、形成栖息地生态仍待验证
- 标品 SKU 需要控制数量，避免生产复杂度过高
