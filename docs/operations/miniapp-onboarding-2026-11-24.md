# 首次使用引导与纯白动物素材

用户确认三页引导稿，并要求动物背景纯白，消除方框图嵌入彩色圆底的效果。本轮仅调整原生小程序，不改官网、后端接口或数据库。

## 实现

- 三页介绍宠物档案、日常照料、养护知识与宠境项目命名；前两页下一步，末页开始我的宠境，每页可跳过。动物没有彩色圆形容器，示例名字和体重明确标注。
- `scripts/prepare-miniapp-onboarding-assets.mjs` 从仓库现有五种动物素材生成专用白底副本，清除与外边缘连通的浅色背景并裁去原图矩形边缘；原物种图片和用户照片不变。输出 256 × 256，周围保留纯白留边。
- 仅普通首页初次冷启动、无查询参数且无外部来源时尝试引导；场景只接受缺省值或 1001/1089。文章、社区、分享与扫码保持原路径与参数；热启动的外部入口取消待展示状态。
- 跳过和完成均回首页，成功导航后才写本机完成标记；重复点击锁定，失败允许重试。导航进入失败时恢复首页读取和真实模式显示，不留下空加载状态。换设备、清除缓存或本机存储不可用时可能再次展示。
- “我的 → 设置 → 使用引导”可主动重看，便于已使用用户检查新界面，不清除其他本机数据。

## 验收范围

- 回归覆盖首次/重复进入、冷/热分享与扫码、导航失败、重复点击、退出失败重试、存储不可用和无效滑动事件。图像检查输出尺寸、外圈纯白及动物主体仍可见。
- 产品经理子 Agent 只读复核；入口失败、热启动和第3页文案问题均已处理。宠境项目目前只支持命名，不宣称已保存完整空间需求或开放硬件配对。
- 官方原生编译、单元测试、原生截图和微信预览分别记录；开发工具内通过不代表手机、体验版或正式发布。
- 本轮 Node 24 Web 单元测试 133 项通过、零跳过；官方编译器通过 19 个 WXML、20 个 WXSS。Git index 的 92 份 active Markdown 校验通过。
- 官方自动化 SDK 在 430 × 834 内容区核对三页、下一步、滑动、完成回首页、跳过及设置重看；完成后重启仍进入真实首页且档案读取结束。三页截图保存在仓库外，纯白外圈另有像素断言。尚未完成不同手机尺寸与手机扫码验收。
