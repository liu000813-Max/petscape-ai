# PETSCAPE 首页增量验收

状态：本轮首页实现与开发工具验证完成，更新后手机验收待确认。当前运行账号仍是测试号，开发预览不代表体验版或正式发布。

## 授权与范围

- 用户提供六屏线稿，并明确最终目标为整套线稿模块；随后选择白底黑字、官网风格、少量粉色，有宠物即可显示体重，首轮增加切宠、头像和体重并保留其他首页内容。
- 最新范围为“先改首页，其他暂时不动”。本轮以该指令实施首页，不新增头像上传入口、硬件连接、启动引导或个人中心。每次后续界面替换先让用户确认。
- 用户明确要求一个产品经理子 Agent；其职责是只读检查代码、产品边界和实现路径，不扩大修改范围。

## 实现

- 首页横排显示宠物家庭，按 ID 选择宠物，当前头像有粉色描边。已有封面照片优先显示，失效后依次回退物种图、emoji；本轮没有新增图片上传能力。
- 有宠物时显示体重模块：最近值、与上次之差、最近七次柱状记录以及展开式 g/kg 输入。无宠物时保留建档入口。
- 体重以当前宠物 ID 写入原有 care-logs，不新增公开接口或迁移，不部署替换后端。显示范围与数据规则见 [内容规范](../specs/miniapp-content.md)。
- 切换时保存各宠物未提交输入；档案重排继续选择同一 ID，删除的宠物不保留草稿。过时的列表与体重响应不能覆盖较新选择。
- 保存期间锁定其他写入和切换直到刷新结束；模糊失败不自动重复写入，明确成功后的刷新失败不报告成保存失败。

## 验证

- 新增七项行为测试先在旧首页失败，再实现通过；覆盖 ID 选择、草稿隔离、晚响应、重复点击、单位换算、记录过滤、读写失败和头像回退。
- 首页与既有请求恢复合计 47 项测试通过，零跳过。修改的两个 Web 测试文件 ESLint 通过。
- 官方原生编译器通过 13 个 WXML、14 个 WXSS。
- 使用仓库外无云凭据快照、独立本机 PostgreSQL 16 新库，全部 16 项迁移成功，Next 构建成功，真实 HTTP 验收 10 项通过、零跳过。新增用例通过页面事件保存 0.325 kg，数据库确认当前宠物仅一条 325g，另一宠物无记录，其他用户列表无法读取该记录。
- 首轮 HTTP 新用例误把其他用户过滤列表的空结果期望为 404；实际既有契约为 200 与空列表，已更正测试，不修改 API。
- HTTP 私有回执：petscape-dev-runtime/postgres16/runs/20261116091310656_d164d0/http-receipt.json。测试使用数据库会话夹具，不能视为本轮新增真实微信登录证据；结束后 PostgreSQL 恢复停止状态。
- 官方开发工具内用实际账号验证：首页与宠物、体重读取成功，空状态和展开输入框实际渲染正常。原生按钮默认宽度曾挤压体重输入，已明确单位切换组和输入宽度后复查截图。
- 产品经理子 Agent 只读审查无体重主流程阻塞，指出养护页有自己保存的宠物选择，首页入口不能承诺直达当前宠物。本轮改用通用养护标题，并在入口写明进入后可选择宠物；补充体重输入范围说明，没有修改养护页。
- 三宠、七次体重的图表布局用临时 setData 显示夹具检查，未发送业务写入，随后恢复真实数据。该截图只证明布局，不是用户的真实档案或体重。
- 私有截图与 visual-receipt.json 位于 petscape-dev-runtime/wechat-diagnostics/home-20261116；图片与会话信息不提交 Git。
