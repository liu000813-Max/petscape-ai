# 头像上传与生命阶段参考验收

范围：宠物档案照片上传、列表同步、物种年月参考；首页既定布局不再改版。用户账号个人头像不在本轮范围。

## 本地结果

- 增加选图、格式及体积校验；原始照片通过现有 API 域名上传并存入私有 OSS。新建后照片失败仍保留宠物 ID，上传成功但绑定响应不明时先核对档案。
- 保留签名上传的 JSON 合同，支持小程序会话；宠物归属在读取上传体前检查，流式读取限制不依赖 Content-Length。Nginx 仅对照片路径放宽大小。
- 针对并行上传将 pending key 的时间戳替换为随机 UUID，避免同一毫秒创建资产的唯一键冲突。
- 物种选择器显示豹纹守宫已有依据的阶段范围，幼年合并规则及老年缺项明确展示；其余未经核实的范围继续待核实。来源与边界见 [规范](../specs/miniapp-life-stages.md)。
- Web 单元测试 100 项通过、零跳过；上传应用用例单元测试 3 项通过；Web 与共享服务端类型检查和修改文件 ESLint 通过；原生编译通过 13 个 WXML、14 个 WXSS。
- 真实 PostgreSQL 16 空库、重复迁移与旧库升级通过，15 项集成测试零跳过。新增用例在真实数据库验证照片归属与绑定，存储为可控适配器，不冒充真实 OSS。
- 隔离目录生产构建与 13 项 HTTP 验收通过、零跳过，包含未登录、跨用户和空图片拒绝；全部在不配置云凭据的环境运行。隔离构建引用现有依赖需将本机快照的 Turbopack 根设为共同工作目录，正式仓库配置未变。私有回执位于 postgres16/runs/20261123020056018_390dd7/http-receipt.json。
- 开发者工具实际显示照片入口，后续照片写入、手机验收、GitHub 与线上结果分别记录。
