# 物种生命阶段参考补充验收

范围：继续已有物种的年月参考任务。用户明确允许补充兽医医院、大学和动物园一手来源；不扩展页面布局、硬件连接或正式账号流程。

## 新增事实及实现

- AAV《Care for Senior Parrots》2022 年版的官方 CDN 文件可读。第 1 页表 1 的 Considered geriatric 栏给出虎皮鹦鹉 >6 年、玄凤鹦鹉 >12 年。仅分别填入两者老年选项，不采用同表的寿命栏推算其他阶段。
- 编辑页通过既有品种/具体物种严格匹配更新选项，既有来源说明展示 AAV 和限制。其他三个阶段继续“年月待核实”，不自动改写主人已选阶段。
- 玉米蛇参考来源从此前不可读的 RVC 页面换为已核对的 Maryland Zoo 文件，仍不将性成熟时间作为成体分界。
- 花枝鼠资料、玉米蛇兽医养护资料和 CEC 蜘蛛资料均未提供本产品可直接采用的四阶段年月，继续待核实。未使用不明博客、商店时间表或实验鼠分期补齐数字。
- 原 AAV、RVC、IVIS 失败地址不重复请求。用户授权扩展来源后才查阅新发布地址。来源和定义见 [生命阶段规范](../specs/miniapp-life-stages.md)。

## 验证

- 106 项 Web 回归测试通过、零跳过，包括鸟类老年范围、其他阶段保留待核实、类别隔离和手动选择不变。
- 官方原生编译通过 13 个 WXML、14 个 WXSS；修改测试文件 ESLint 通过。
- 微信开发工具实际运行表单事件，确认虎皮显示超过 6 年、玄凤超过 12 年，输入仅“鹦鹉”全部待核实，三次操作均保持阶段待确认。只使用未保存表单，不写入用户档案。
- 产品经理子 Agent 只读审查通过，核对了表格列和物种对应关系。

本轮仅修改客户端参考数据、测试及文档，无 API、数据库或后端配置变更。正式账号仍是独立待办，不将本次开发预览称为体验版发布。

## 花枝鼠老年参考补充

- 用户继续任务后，新增核实 Molesey Vets 宠物大鼠页面：该院将超过 18 个月作为老年养护参考，强调个体差异；家养大鼠 RATTUS 原始兽医研究亦采用超过 1.5 年的老年描述。原文与定义见 [规范](../specs/miniapp-life-stages.md)。
- 花枝鼠老年选项改为“超过 1 年 6 个月”，另外三阶段维持待核实。新建默认花枝鼠时即显示，不需要重复输入品种；切到其他物种后不沿用此范围。其他异宠仅明确的宠物大鼠名称或学名可匹配，仓鼠、沙鼠及泛称不匹配。
- 产品经理子 Agent 限量核对三个玉米蛇/捕鸟蛛来源，未取得可新增的阶段年月。此轮不扩大到新物种，不用生长、性成熟或寿命补齐缺项。
- 107 项 Web 回归通过、零跳过，修改测试 ESLint 通过，官方编译通过 13 个 WXML、14 个 WXSS。开发工具实际验证新建花枝鼠显示、切到蛇类清除参考、切回恢复、仓鼠不套用，阶段始终由主人选择；没有写入档案。
- 本次为客户端参考补充，无数据库迁移或后端变更。GitHub 同步和开发预览在实际成功后交付，手机显示未单独验收。
