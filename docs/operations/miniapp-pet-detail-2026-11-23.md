# 单宠详情页实现与验收

用户确认本轮按单宠详情稿实现：从首页圆形头像进入该宠物详情，右侧保留「编辑档案」。宠物与我的列表继续保留原有入口。

- 详情读取已登录用户的现有宠物档案和最多 100 条近期养护记录。体重与首页共用单位解析，折线和从零起算的柱图使用相同的最近最多 7 次有效记录；单次折线只显示一个数据点。近期养护列出最近三条非体重记录。
- 养护入口按详情页的宠物 ID 预选；若档案已不可用，提示返回选择，避免自动切到另一只宠物后误写。点编辑档案或养护后返回，详情重新读取。
- 档案和养护失败有独立状态；旧请求不能覆盖刷新后的记录。温湿度区继续显示未连接，设备配对暂未开放。本轮不改 API、数据库、官网和账号发布配置。
- Node 24 Web 单元测试 125 项通过；微信官方编译器编译 18 个 WXML、19 个 WXSS。
- 官方开发工具以现有账号读取线上档案，核对首页侧边头像导航、编辑 ID、养护预选、实际柱状图和养护行；使用独立显示夹具截取折线及三行养护布局，未写入线上数据。截图不包含真实宠物资料，保留在仓库外。
- 官方开发预览与手机验收分开；开发工具证据不代表真机或正式发布。
