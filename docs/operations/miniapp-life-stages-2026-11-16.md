# PETSCAPE 档案字段与生命阶段验收

状态：本地实现与测试完成，线上部署和手机验收待核验。

用户要求移除小程序体型等级，并以幼年、亚成体、成体、老年展示生命阶段和不同物种年月；随后同意缺乏可靠范围时标“年月待核实”。产品规则及本轮资料来源见 [规范](../specs/miniapp-life-stages.md)。

## 已实现

- 删除小程序体型滑块、默认等级、事件处理与提交字段。mock 新建不再生成无依据等级 3；API 与历史数据库字段保留。
- subadult 独立加入 Prisma 枚举、共享 contract 与应用 DTO，新 migration 由 Prisma migrate diff 对比本轮修改前后 schema 生成，SQL 仅追加一个枚举值。
- 新建与编辑支持四阶段及待确认。列表显示中文，未识别旧阶段明确提示重新确认；具体物种参考索引使用严格别名匹配，不由粗分类推断年月。
- 官网仅补充亚成体选项和成体名称，以兼容共享字段，不改动官网体型输入或布局。

## 本地验证

- 五项新增表单和 contract 行为测试先在旧实现失败，再实现通过。最终相关单元回归 61 项通过、零跳过。产品经理只读审查补充了“未识别旧阶段须显式确认再保存”，并用失败用例复现后修复，防止只改名字就覆盖原阶段。
- 官方编译器通过 13 个 WXML 和 14 个 WXSS；Prisma validate、generate、共享服务端 TypeScript 检查通过。修改的 Web 和共享服务端文件 ESLint 通过。
- 真实 PostgreSQL 16 验证全部 17 项迁移、重复迁移无变更、16 项旧版本升级到新版本。旧账号、微信账号关联、Session、宠物生命阶段与体型字段逐行对比未改变，升级后可保存 subadult。
- 社区及宠物真实数据库集成 14 项通过、零跳过。私有回执位于 petscape-dev-runtime/postgres16/runs/20261116104710732_13250e/receipt.json。
- 仓库外无云凭据快照的 Next 构建成功，真实 HTTP 与 PostgreSQL 验收 11 项通过、零跳过；实际页面提交亚成体，数据库确认新建 sizeLevel=null、编辑省略体型后旧值 4 保留。私有回执：petscape-dev-runtime/postgres16/runs/20261116104911869_a246a3/http-receipt.json。
- 线上发布结果在实际完成后追加；不由本地通过推断预览或生产已更新。
